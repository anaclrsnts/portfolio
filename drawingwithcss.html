I created this CSS art collection to explore how illustrations and simple animations can be built directly in the browser. The project includes a tortoise, satellite, parrot, dragon, ice cream, and bouncing ball created through HTML structure and CSS styling.

Technical Overview

Each illustration is divided into smaller visual elements and assembled through HTML containers and CSS classes.

Shapes are created by combining dimensions, borders, border-radius, transforms, gradients, and positioned elements.

The bouncing ball also introduces movement through CSS animation, showing how the same styling language can control both appearance and motion.

Main Features

• Collection of six CSS illustrations.

• Tortoise, satellite, parrot, dragon, and ice cream compositions.

• Animated bouncing ball created with CSS.

• Layered visual elements assembled directly in the browser.

• Use of CSS shapes, transforms, gradients, and rounded borders.

• Published and accessible through GitHub Pages.

Creative Process

I approached each drawing by first breaking the reference into simple geometric shapes and identifying how those parts could overlap to form the complete illustration.

I then adjusted the size, color, position, rotation, and stacking order of each element until the composition matched the intended character or object.

Building several different illustrations helped me test the same CSS concepts across organic characters, mechanical objects, food, and animation.

Challenges

• Translating detailed illustrations into simple HTML elements.

• Positioning small parts precisely within each composition.

• Managing overlapping elements and their stacking order.

• Reusing CSS techniques across illustrations with very different shapes.

• Creating smooth movement for the bouncing ball animation.

What I Learned

• I improved my understanding of CSS positioning and stacking contexts.

• I practiced building complex visuals from smaller reusable shapes.

• I became more comfortable using transforms, gradients, borders, and border-radius creatively.

• I learned how CSS keyframes can turn a static illustration into an animated element.

• I strengthened my visual debugging and attention to detail.
