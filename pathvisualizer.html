This interactive pathfinding visualizer demonstrates how different search algorithms explore a grid to find the shortest path between two points. Users can draw walls, move the start and end nodes, compare algorithms, and watch every step through smooth animations.

Technical Overview

The application uses a collection of image objects to create a 4 × 4 memory board. Eight items are randomly selected, duplicated to form matching pairs, shuffled, and then added to the page dynamically.

JavaScript controls the card-selection flow, stores the first and second selected cards, compares their values, updates the move counter, manages the timer, and verifies the final win condition.

The interface is updated through DOM manipulation and CSS classes, without the use of a front-end framework.

Main Features

• Dynamic generation of a 4 × 4 card grid.

• Random card selection and shuffling for each new game.

• Interactive card-flip behavior.

• Automatic comparison and detection of matching pairs.

• Move counter updated after each pair selection.

• Timer that tracks the duration of the game.

• Start and stop controls for managing the game session.

• Win message displaying the player's final number of moves.

Application Flow

When the player starts a new game, the timer and move counter are reset, the cards are randomly generated, and the game board becomes visible.

The player selects two cards at a time. If the cards match, they remain visible and are marked as completed. If they do not match, they are flipped back after a short delay.

The game ends when all card pairs have been found, and the final move count is displayed to the player.

Challenges

• Generating card pairs dynamically while ensuring that each selected item appeared exactly twice.

• Keeping track of the first and second selected cards during each turn.

• Synchronizing the card state, move counter, timer, and win condition.

• Managing the delay before unmatched cards were flipped back over.

• Updating the interface dynamically without using a framework.
