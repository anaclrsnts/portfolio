Project Overview

The interface displays a selection of X-Men characters alongside a larger area containing information about the currently selected character.

When a user selects a character, JavaScript removes the active state from the previous option, highlights the new selection, and updates the main character image, name, and description.

This creates an interactive experience using native JavaScript, without relying on a front-end framework.

Main Features

• Interactive selection between multiple X-Men characters.

• Dynamic update of the selected character image.

• Dynamic update of the character name and description.

• Visual indication of the currently selected character.

• Responsive interface for different screen sizes.

• Deployment through GitHub Pages.

Interaction Flow

The page initially presents Cyclops as the selected character.

When another character is selected, the application identifies the clicked element and reads the corresponding character information.

The selected class is transferred to the new character, while the main image and text content are updated in the interface.

Challenges

• Connecting each character option to the correct image and description.

• Updating multiple interface elements from a single user interaction.

• Managing the selected visual state across all character options.

• Keeping the layout usable across desktop and smaller screens.

• Maintaining consistency between the HTML structure, CSS classes, and JavaScript behavior.

What I Learned

• I improved my understanding of JavaScript event listeners.

• I practiced selecting and updating HTML elements through the DOM.

• I learned how CSS classes can represent and control interface states.

• I became more comfortable connecting user interactions to visual changes.

• I strengthened my understanding of responsive front-end development.
